# Zenphoria — Psychological Education & Clinical Wellness

A luxury editorial web application built with **React + Vite**, featuring the complete design system and pages from the Zenphoria Figma/mobile designs:

1. **Home** (`HomePage.jsx`): Hero with calming consultation interior, methodology cards (*Cognitive Mapping*, *Emotional Regulation*, *Behavioral Alignment*), recent clinical readings, priority CTAs, and editorial footer.
2. **The Five Pillars** (`PillarsPage.jsx`): Comprehensive framework exploring *Identity*, *Emotional Patterns*, *Relational Dynamics*, *Modern Emotional Life*, and *Psychological Education* with core tags.
3. **Step Assessment / Focus Quiz** (`AssessmentPage.jsx`): 3-step interactive consultation onboarding (*Stress & Anxiety*, *Relationships*, *Personal Growth*, *General Consultation*), cadence selection, and contextual intake notes.
4. **Journal & Resources** (`JournalPage.jsx`): Publication library with live search, topic filtering (*Clinical Frameworks*, *Mindfulness*, *Cognitive Load*), featured insights banner, and interactive full-text article reading modal.
5. **Interactive Controls & Modals**:
   - Device Preview Switcher (Toggle between Mobile phone frame and Responsive Desktop view).
   - Priority Intake & Waiting List Modal with interactive form validation & reservation confirmation.
   - Slide-out Navigation Drawer with smooth animations.

---

## 🚀 Running the Project

Navigate to the `frontend` folder:

```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:5173/](http://localhost:5173/) in your browser.
